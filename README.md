A simple patcher for the <a href="https://www.jan.ai/"> Jan.ai</a> desktop application, giving it an AMOLED theme <br>
Tested with Jan on version 0.8.4, only works with native packages at the moment (not Flatpaks or Appimages) <br>
Packaged as a debian package, licensed under The Unlicense


Also includes an optional noCSD mode, which hides the HTML window decorations (minimize/maximize/close), this is useful if you want to use Jan with the system window decorations, instead of Jan's own
